S1 · Lecture

Classical to quantum mechanics: postulates

Classical (Newtonian) mechanics assigns a particle an exact position and momentum at every instant and predicts its path. It works for cricket balls and planets, but around 1900 three experiments showed it fails for electrons and light.

Three failures of classical physics

  1. Blackbody radiation.Classical theory predicted infinite energy at short wavelengths (the “ultraviolet catastrophe”). Planck fixed it by assuming that oscillators exchange energy only in packets:
    E = hν h = 6.626×10⁻³⁴ J s
  2. Photoelectric effect.Light ejects electrons only if its frequency exceeds a threshold, however bright it is. Einstein: light is made of photons of energy hν, and one photon frees one electron:
    KE(max) = hν − φ (φ = work function)
  3. Atomic spectra.Hydrogen emits only certain wavelengths (lines), not a continuum. The lines obey the Rydberg formula, and classically an orbiting electron should spiral into the nucleus:
    1/λ = R_H (1/n₁² − 1/n₂²) R_H = 1.097×10⁷ m⁻¹

Matter waves

de Broglie proposed that every particle has a wavelength, λ = h/p. Example: an electron accelerated through 100 V has p = √(2meV), so λ = h/√(2meV) ≈ 0.123 nm, comparable to atomic spacing (this is why electrons diffract from crystals). A 0.15 kg ball at 40 m/s has λ ≈ 10⁻³⁴ m, far too small to notice.

The postulates of quantum mechanics

  1. Postulate 1: state.The state of a system is completely described by a wavefunction ψ(x,y,z,t).
  2. Postulate 2: Born interpretation.|ψ|²dτ is the probability of finding the particle in volume dτ. Since the particle must be somewhere, ∫|ψ|²dτ = 1 (normalization).
  3. Postulate 3: operators.Each observable has an operator: position x̂ = x, momentum p̂ₓ = −iħ d/dx, energy Ĥ = −(ħ²/2m)∇² + V.
  4. Postulate 4: measurement.A measurement can only give an eigenvalue a of the operator, where Âψ = aψ. Check: p̂ acting on e^(ikx) gives −iħ(ik)e^(ikx) = ħk e^(ikx), so the momentum is ħk = h/λ, matching de Broglie.
  5. Postulate 5: dynamics.The state evolves by iħ ∂Ψ/∂t = ĤΨ.

Uncertainty principle

Because x̂ and p̂ do not commute, position and momentum cannot both be known exactly:

Δx · Δp ≥ ħ/2

It is not instrument error; it is built into wave behaviour. Confining an electron to a small region (small Δx) forces a large Δp, which is the reason a confined particle has zero-point energy.

S2 · Lecture

The Schrödinger equation: derivation and meaning

Schrödinger did not prove his equation from earlier physics; it is a postulate that fits experiment. But it can be motivated in four short steps, by combining the wave picture of the electron with energy conservation.

  1. Start with a standing wave. A wave in one dimension with wavelength λ can be written ψ = A sin(2πx/λ). Differentiate twice:
    dψ/dx = (2π/λ) A cos(2πx/λ) d²ψ/dx² = −(2π/λ)² A sin(2πx/λ) = −(2π/λ)² ψ
  2. Bring in the electron’s wavelength. de Broglie: λ = h/p, so 2π/λ = 2πp/h = p/ħ (where ħ = h/2π). Substituting:
    d²ψ/dx² = −(p²/ħ²) ψ
  3. Bring in energy. Total energy = kinetic + potential: E = p²/2m + V(x). Rearranged, p² = 2m(E − V). Substituting this for p²:
    d²ψ/dx² = −(2m/ħ²)(E − V) ψ
  4. Rearrange. Multiply by −ħ²/2m and move Vψ across:
    −(ħ²/2m) d²ψ/dx² + V(x) ψ = E ψ
    This is the time-independent Schrödinger equation in one dimension.

Reading the equation

The first term is the kinetic-energy operator. d²ψ/dx² measures how sharply ψ curves, so a more tightly curved (more “wiggly”) wavefunction has higher kinetic energy. The second term is potential energy. Together they form the Hamiltonian operator Ĥ, giving the compact form Ĥψ = Eψ: an operator acting on a function returns the same function times a number. Such a function is an eigenfunction and the number E is its eigenvalue, the allowed energy. In three dimensions d²/dx² becomes the Laplacian ∇² = ∂²/∂x² + ∂²/∂y² + ∂²/∂z².

Why energy becomes quantized

Mathematically the equation has solutions for every E. Physically ψ must be (1) single-valued, (2) continuous with a continuous slope where V is finite, (3) finite everywhere, and (4) normalizable: ∫|ψ|²dτ = 1. Only certain values of E allow a solution that meets these boundary conditions, and that is the origin of quantization. The next topic shows this happening.

Time-dependent form

When the state changes in time: iħ ∂Ψ/∂t = ĤΨ. If V does not depend on time, Ψ(x,t) = ψ(x)·e^(−iEt/ħ), and the spatial part obeys the equation above. These stationary states have |Ψ|² independent of time.

Ĥψ = Eψ Ĥ = −(ħ²/2m)∇² + V |ψ|² = probability density

Particle in a 1-D box: full solution

The model. A particle of mass m moves along x between impenetrable walls at x = 0 and x = L. Inside, the potential is zero; outside, it is infinite.

V(x) = 0 for 0 < x < L V(x) = ∞ for x ≤ 0 or x ≥ L

Since the particle cannot be where V is infinite, ψ = 0 outside the box. Only the inside needs solving.

  1. Write the equation inside the box (V = 0).
    −(ħ²/2m) ψ″ = E ψ → ψ″ = −k² ψ, where k² = 2mE/ħ²
  2. Solve it. Functions whose second derivative is −k² times themselves are sine and cosine, so
    ψ(x) = A sin(kx) + B cos(kx)
  3. Apply the boundary condition at x = 0. ψ must be continuous with the outside value 0:
    ψ(0) = A·0 + B·1 = 0 → B = 0 so ψ = A sin(kx)
  4. Apply the boundary condition at x = L.
    ψ(L) = A sin(kL) = 0
    A = 0 would give ψ = 0 everywhere (no particle), so sin(kL) = 0, hence
    kL = nπ → k = nπ/L, n = 1, 2, 3, …
    n = 0 is excluded (ψ = 0); negative n only flips the sign of ψ, the same state. Quantization has appeared from the boundary conditions alone.
  5. Find the energies. From k² = 2mE/ħ² we have E = ħ²k²/2m. Insert k = nπ/L and ħ = h/2π:
    Eₙ = ħ²n²π²/(2mL²) = n²h²/(8mL²)
  6. Normalize. The particle is somewhere in the box, so the total probability is 1:
    ∫₀ᴸ A² sin²(nπx/L) dx = A²·(L/2) = 1 → A = √(2/L)
    (the integral of sin² over a whole number of half-waves is half the length.)
    ψₙ(x) = √(2/L) · sin(nπx/L)

What the result tells us

Energy is quantized: only n² multiples of h²/8mL². Zero-point energy: the lowest level is n = 1, not 0, so E₁ = h²/8mL² > 0. A confined particle can never be at rest (consistent with the uncertainty principle). Nodes: ψₙ has n − 1 nodes between the walls, and more nodes mean more curvature and more energy. Spacing: Eₙ₊₁ − Eₙ = (2n + 1)h²/8mL². Levels spread apart for higher n and for smaller L or m; for a macroscopic mass the spacing is immeasurably small, which is why we see continuous energy in everyday life.

Worked example: electron in a 1.0 nm box

E₁ = h²/8mL² = (6.626×10⁻³⁴)² / (8 × 9.109×10⁻³¹ × (10⁻⁹)²) = 6.03×10⁻²⁰ J = 0.376 eV E₂ = 4E₁ = 1.50 eV E₃ = 9E₁ = 3.38 eV n = 1 → 2 absorption: ΔE = 3E₁ = 1.13 eV → λ = 1240/1.13 ≈ 1100 nm (near-infrared)

Probability: where is the particle?

|ψₙ|² is the probability density. For n = 1 the particle is most likely at the centre and never at the walls. Probability of being in the left quarter (0 to L/4):

P = (2/L)∫₀^(L/4) sin²(πx/L) dx = [x/L − sin(2πx/L)/2π] from 0 to L/4 = 1/4 − 1/(2π) ≈ 0.091 (a classical particle would give 0.25)

For large n the density flattens to the classical value 1/L (the correspondence principle). Why it matters in chemistry: treating the π electrons of a conjugated chain as particles in a box (L ≈ chain length) predicts that longer chains have smaller gaps and absorb at longer wavelengths, the same reason quantum dots change colour with size.

Eₙ = n²h²/8mL² ψₙ = √(2/L) sin(nπx/L) ΔE = (2n+1)h²/8mL²

The hydrogen atom: full solution

The hydrogen atom is the one atom whose Schrödinger equation can be solved exactly. The potential comes from Coulomb attraction between the electron and the nucleus.

V(r) = −e²/(4πε₀r)

Because V depends only on the distance r, spherical polar coordinates (r, θ, φ) are natural, and the equation separates into independent pieces.

Step-by-step solution

  1. Separate the variables.Write ψ(r,θ,φ) = R(r)·Θ(θ)·Φ(φ) = R(r)·Y(θ,φ). Substituting into Ĥψ = Eψ and dividing by RY gives one side depending only on r and the other only on angles. Each must equal a constant, called l(l+1).
  2. Azimuthal equation.The φ part is d²Φ/dφ² = −mₗ²Φ with solution Φ = e^(imₗφ). Going once round the axis (φ → φ + 2π) must return the same value, so mₗ must be an integer: 0, ±1, ±2, …
  3. Polar equation.The θ equation has finite solutions only if l is a non-negative integer and |mₗ| ≤ l. Together Θ·Φ = Y_l^mₗ(θ,φ) are the spherical harmonics, which fix the shape of the orbital.
  4. Radial equation.The remaining equation contains the Coulomb term plus the centrifugal term l(l+1)ħ²/2mr². It has acceptable (finite, normalizable) solutions only if
    E = −13.6 eV / n² n = 1, 2, 3, … and l ≤ n − 1
    This is where the principal quantum number n comes from.

The quantum numbers

n (size and energy): 1, 2, 3 … l (shape): 0 to n − 1, labelled s, p, d, f. mₗ (orientation): −l to +l, giving 2l + 1 orbitals. Hence n = 2 has one 2s and three 2p orbitals; the total number of orbitals in shell n is n². (Spin mₛ = ±½ is a separate fourth number.) All l values of a given n share the same energy in hydrogen (degenerate).

The 1s orbital in detail

ψ₁ₛ = (1/√(πa₀³)) e^(−r/a₀) a₀ = 4πε₀ħ²/me² = 52.9 pm

It has no angular dependence (a sphere) and is largest at the nucleus. But the chance of finding the electron at distance r in a thin shell is the radial distribution function, P(r) = 4πr²ψ², which includes the growing shell volume:

P(r) = (4/a₀³) r² e^(−2r/a₀) dP/dr = 0 → 2r − 2r²/a₀ = 0 → r = a₀

So the most probable distance is the Bohr radius, even though ψ itself peaks at r = 0.

Nodes and shapes

Radial nodes (spheres where ψ = 0) number n − l − 1, and angular nodes (planes or cones) number l. Total nodes = n − 1. 2s has one radial node at r = 2a₀. 2p has one angular node (a plane through the nucleus), giving two lobes of opposite sign. 3d has two angular nodes (four lobes, mostly).

Energy example

n = 2 → 1: ΔE = 13.6(1 − 1/4) = 10.2 eV λ = 1240 eV·nm / 10.2 eV = 121.6 nm (Lyman-α line, ultraviolet)

Tutorial: the significance of ψ

ψ itself has no direct physical meaning and may be negative or complex. |ψ|² is the probability density. The sign (phase) of ψ matters when orbitals overlap: same signs add (bonding), opposite signs cancel (antibonding), which leads straight into molecular orbitals.

Molecular orbitals and Hückel theory

A molecular orbital (MO) is a one-electron wavefunction spread across the whole molecule. The standard approach builds it from atomic orbitals (LCAO).

LCAO for H₂⁺ and H₂

  1. Trial function.ψ = c_A φ_A + c_B φ_B, with φ_A and φ_B the 1s orbitals on atoms A and B.
  2. Variation principle.The best coefficients are those that minimize E = ∫ψĤψ dτ / ∫ψ²dτ. Minimizing with respect to c_A and c_B gives the secular equations, which have a non-zero solution only if the secular determinant is zero:
    | H_AA − E H_AB − ES | | H_AB − ES H_BB − E | = 0
    where α = H_AA = H_BB (Coulomb integral, the energy of an electron on one atom), β = H_AB (resonance integral, negative) and S = ∫φ_Aφ_B dτ (overlap).
  3. Solve.For identical atoms (α − E)² = (β − ES)², giving
    E₊ = (α + β)/(1 + S) ψ₊ = (φ_A + φ_B)/√(2 + 2S) bonding E₋ = (α − β)/(1 − S) ψ₋ = (φ_A − φ_B)/√(2 − 2S) antibonding
    Because β < 0, ψ₊ is lower than α (electron density builds up between the nuclei), and ψ₋ is higher than α, with a node between the nuclei. The antibonding rise is larger than the bonding drop.

Rules and diatomic molecules

Orbitals combine when they have similar energy, enough overlap and the same symmetry. N atomic orbitals make N MOs. Fill from the lowest with two electrons each (Pauli) and Hund’s rule for degenerate levels.

Bond order = ½ (electrons in bonding − electrons in antibonding)

For O₂, F₂ the order is σ2s < σ*2s < σ2p < π2p < π*2p < σ*2p. For Li₂ to N₂, s–p mixing puts π2p below σ2p. Examples:

He₂ B.O. = ½(2 − 2) = 0 does not exist N₂ B.O. = ½(10 − 4) = 3 very strong, diamagnetic O₂ B.O. = ½(10 − 6) = 2 two unpaired electrons in π* → paramagnetic O₂⁺ 2.5 O₂⁻ 1.5 (bond length rises as order falls)

Hückel theory for π systems

For planar conjugated molecules, treat only the π electrons, build each π MO from carbon 2p orbitals, and make three simple assumptions: all Coulomb integrals = α, resonance integral β between bonded neighbours only, and S = 0 and no other interactions. Dividing the secular determinant by β and writing x = (α − E)/β gives a determinant with x on the diagonal and 1 for each bonded pair.

Butadiene (4 carbons in a chain)

| x 1 0 0 | | 1 x 1 0 | | 0 1 x 1 | = 0 → x⁴ − 3x² + 1 = 0 → x² = (3 ± √5)/2 | 0 0 1 x | x = ±1.618, ±0.618 so E = α ± 1.618β, α ± 0.618β

With 4 π electrons filling the two lowest MOs: E(π) = 2(α + 1.618β) + 2(α + 0.618β) = 4α + 4.472β. Two isolated ethylene double bonds would give 4α + 4β, so the delocalization energy = 0.472|β|. The lowest MO is ψ₁ = 0.372φ₁ + 0.602φ₂ + 0.602φ₃ + 0.372φ₄, with no nodes, so the central C–C bond has partial double-bond character. The HOMO is ψ₂ and the LUMO is ψ₃, so the HOMO–LUMO gap is 1.236|β|.

Benzene (ring of 6 carbons)

Eₖ = α + 2β cos(2πk/6), k = 0…5 α + 2β α + β (×2) α − β (×2) α − 2β E(π) = 2(α+2β) + 4(α+β) = 6α + 8β

Three isolated double bonds would be 6α + 6β, so the delocalization energy is 2|β| (the aromatic stabilization). All six C–C bonds are equal, the lowest MO is a ring-wide delocalized cloud, and the HOMO is a degenerate pair.

Tutorial note

Always follow this sequence: draw the skeleton → write the determinant → solve for x → convert to E → fill electrons → sum the energy → compare with localized double bonds.
